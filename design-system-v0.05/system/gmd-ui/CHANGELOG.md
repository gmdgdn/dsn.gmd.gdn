# 0.7.0 — 2026-10-05

Refined all 61 primitive families with documented GMD slot/state treatments. Added validation, loading and icon comparison board; ten public website blocks; six bilingual page templates; Lucide sizing and RTL icon contract; representative native Pen refinement board. Fixed global table filtering, combobox demo filtering, drawer initial focus, popover naming, form specimen width, slider track, switch thumb and checkbox indeterminate glyph. Catalog now wraps header actions and code at mobile widths. Registry adds icon, website block and page items with editable CSS and Fontsource fonts. Existing 0.6 endpoints remain pinned.

Updating installed source requires reviewing your own changes. PopoverTitle is now a semantic h2 and titles participate in automatic naming when directly composed; custom wrappers should provide aria-label or aria-labelledby. Photography is supplied by the consuming application through PagePatterns.assetBase.
