GMD / OPEN COMPONENT SYSTEM / 0.7.2

Egyptian context.
Reusable interface foundations.

Square ink frames, hard depth, Nile focus, editorial registers and bilingual typography. Built on owned shadcn source with accessible primitives; project roles can be remixed for Film and Archive.

Install

Initialize shadcn in a React + Tailwind 4 project first. Install one component or the full system.

pnpm dlx shadcn@latest add https://gmd-ui-registry.anagmdgdn.workers.dev/r/v0.7.2/button.json
pnpm dlx shadcn@latest add https://gmd-ui-registry.anagmdgdn.workers.dev/r/v0.7.2/gmd-all.json
