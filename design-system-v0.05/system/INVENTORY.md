## Entry points and consumers

The current top-level coded entry is [`integration/index.html`](../integration/index.html), a working review gallery served locally. It consumes [`integration/tokens.css`](../integration/tokens.css), `system.css`, and `app.js`; [`tokens.json`](../integration/tokens.json) is documented as its token source. The asset build script emits token CSS and parses curated SVGs.

The current public-company preview is [`integration/ui-templates/gmd/index.html`](../integration/ui-templates/gmd/index.html), with Company, Products, Services, Data, and Contact pages. It uses shared integration tokens plus the premium shell and typography files under `ui-templates/`; it is a static web prototype. The earlier `marketing/`, `collection/`, and `editorial/` pages are explicitly deferred. The other notable review entry points are `integration/expansion/index.html`, `integration/expansion/component-lab.html`, `integration/expansion/geometry.html`, `integration/egypt-library/index.html`, `integration/egypt-library/graphics-3/gallery.html`, and `integration/social/index.html`.

`integration/README.md`, `MANIFEST.md`, `PEN-INTEGRATION.md`, and `BOARD-UNIFICATION.md` document the cross-surface decisions. They identify 13 unified GMD boards and map readable IDs to exports. Their statements do not replace opening the active Pen document or qualify the underlying encrypted source; those files were not inspected here. Consumer applications Film, Kayffa, and Data still need separate adapters/build validation as stated in readiness docs.

## Foundations and drift to resolve

- **Color/shape master:** `integration/tokens.json` is the documented canonical token input. `tokens.css` declares CSS aliases from it and is generated by `integration/scripts/build_assets.py`. Core values include ink `#140206`, paper `#F7F4EF`, Nile `#1034A6`, pink `#FF6183`, square editorial corners, 1px borders, and 5/3/0 hard depth. Expansion `theme.json`/`theme.css` are additive, optional ornament/state/density roles, not a second master.
- **Typography migration:** the older generated `tokens.css` and `MANIFEST.md` bundle Perfectly Nineties, Suisse Intl, FK Raster, Noto Naskh Arabic, and Noto Sans Arabic. Current `ui-templates/typography.css` instead assigns Source Sans 3 / Source Serif 4, Mada / Amiri, and selective Handjet, while retaining Perfectly Nineties as optional brand display. This is a documented evolution, but legacy pages and CSS still contain old font roles; make the typography stylesheet the explicit current-page contract and avoid mixing fallback roles silently.
- **Duplicate font payloads:** Amiri regular/bold files and the Amiri OFL notice are byte-identical in `egypt-library/fonts/` and `ui-templates/fonts/`. The prior v0.05 Noto/Suisse/Perfectly/FK bundle also duplicates `direction-review/fonts/` inputs. Egyptian library additionally includes IBM Plex Sans Arabic and Rakkas as optional specimens. These are separate static copies, not evidence of independently maintained versions.
- **Palette aliases:** older `gmd.css`, `premium.css`, token aliases, and `theme.css` each express some shared roles. Keep `tokens.json` authoritative and distinguish page/component aliases from token definitions. The added ornament colors are optional and must not replace the canonical Nile/ink/paper defaults.
- **Exact duplicated exports/source copies:** SHA-256 inventory finds exact PNG duplication between `pen-exports/` and `unified-boards/` for shared boards; the unified and archive folders intentionally retain visual snapshots. Several G3 source files exactly duplicate G2 sources under different IDs (G3-001/G2-017, G3-002/G2-005, G3-014/G2-014, G3-015/G2-022, G3-021/G2-002). Preserve ID-specific catalog context; do not treat duplicate bytes as separate visual evidence. `ui-templates/gmd/previous-public/` duplicates current-generation CSS/JS for historical reference.

## Maturity vocabulary used here

- **Verified:** a recorded check supports the narrowly stated behavior or artifact integrity; does not mean whole-product release.
- **Prototype:** runnable local page, interaction, or authored composition with meaningful scope/QA boundaries.
- **Reference:** evidence, source, static visual export, or candidate asset that informs design but is not a supported consumer API.
- **Legacy:** superseded/archived version kept for provenance or comparison.

The detailed machine-readable inventory is [`registry.json`](registry.json). It records grouped deliverables rather than every individual image/font file; the tree and manifests remain the authoritative per-asset lists.
