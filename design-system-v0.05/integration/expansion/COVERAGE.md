### Shared review pass for every component

- Name the component consistently in Pen, CSS and runtime; state whether it is an observed Tavus pattern, a GMD adaptation, or a new requirement.
- Record anatomy, supported content length, density/size variants, state model, events/slots, and token roles. Avoid defining behavior from a still image alone.
- Check pointer and keyboard use, visible focus, reading order, status announcements, Escape and focus return where applicable, reduced motion, and touch target size.
- Review desktop, tablet and narrow layouts with long English/Arabic labels, mixed-direction identifiers, missing media, empty, loading, error and many-item cases. The Tavus 390 × 844 attempt in the inventory remained 1026 × 668 and is not valid responsive evidence.
- Label historical/geometric source status at the asset or specimen. Current source guides: [`DIRECTION.md`](../../direction-review/DIRECTION.md), [`VISUAL-REVIEW.md`](../../deep/VISUAL-REVIEW.md), [`MANIFEST.md`](../MANIFEST.md).
