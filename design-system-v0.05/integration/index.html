GMD / SHARED RULES

The component contract.

Titles, metadata and actions use the same token roles in Film, Kayffa and Data. Their surrounding compositions adjust density and imagery.

  1. Keep source and interpretation next to the visual.
  2. Use a square hit target even around shaped media.
  3. Make selection and status understandable in text.
  4. Provide an ordinary reading order and keyboard route.
