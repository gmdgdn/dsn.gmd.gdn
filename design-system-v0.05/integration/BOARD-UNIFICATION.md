# Unified GMD board set

3 October 2026. The user extended the approved expansion plan to the older GMD boards. This pass migrates the existing boards; the larger component and geometry backlog remains planned work.

All 13 GMD boards in the active Pen document now use the `GMD Unified v0.05` naming prefix. The original imported Tavus reference frames are separate source evidence. The earlier standalone v0.01 files remain archival references, while the editable GMD board set carries the current shared guidance.

## Shared decisions applied

- Palette references use `gmd-shared-*` variables for ink, paper, warm, surface, charcoal, muted, Nile, pink and sand, with separate status surfaces.
- Display, interface, utility and Arabic text use Perfectlynineties, Suisse Intl, FK Raster and Noto Sans Arabic. Mixed Arabic/Latin specimens use Arabic-capable text styles.
- The old radius-2 editorial guidance now specifies square frames, ink rules and deliberate 5/3/0 hard depth. Primary/secondary catalog masters receive the shared ink edge and default hard offset.
- The outdated instruction to mirror hard-shadow direction in RTL is removed. Reading order and directional controls mirror independently of brand depth.
- The old status swatch now matches its actual Nile fill. The catalog status sample uses the shared pale-blue surface instead of an unrelated green treatment.
- Unverified production, restoration, custody and seamless-repeat claims in the Antigravity boards are replaced with study descriptions. Geometry and icon candidates are distinguished from the curated assets.
- Six curated utility glyphs appear as real editable native paths in the older icon taxonomy board. Future icon cells remain candidates, not released glyphs.
- The Film layout synopsis and metadata are wrapped within their panel; illustrative content is identified as such.
