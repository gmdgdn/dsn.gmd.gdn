Pattern borders must not conceal source details.

## Editable versus raster

These four PNGs are raster compositions. The motif atlas and new-graphics SVG library contain editable vector parts; use those for exact palette changes, responsive dividers and scalable drawings. Keep pixel/photo treatments separate from the vector frame so projects can replace the image without redrawing the component.

Pen image fills use document-relative `images/...` references. Copies live beside the active Pen document; the project assets remain the portable source. SVG masters are native paths/groups on their asset boards.
