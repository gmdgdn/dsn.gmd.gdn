Example named-part/color edit

SVG groups are named in the DOM so an editor can select the component. The role classes have a fixed SVG color and a CSS custom-property override for flexible previews and consuming products.

<g id="fan-wedges" aria-label="16 radial fan wedges"> … </g>
 .inkfill { fill: #140206; fill: var(--gmd-ink, #140206); }
 svg.style.setProperty('--gmd-ink', '#1034A6');

Fallback colors preserve visible rendering if an editor drops custom properties. The palette buttons above apply to inline SVG previews; download files are unchanged.
