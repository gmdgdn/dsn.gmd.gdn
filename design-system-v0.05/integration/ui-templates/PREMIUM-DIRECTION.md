# GMD public website — premium multipage phase

Saved 4 October 2026. Main entry: gmd/index.html.

## What changed
Six distinct public pages: Home, Company, Products, Services, Data and Contact. Earlier public sources are preserved in gmd/previous-public; older product/workspace drafts stay separate.

The saved Tavus Pen homepage, vision and CVI sections were reviewed for media-led openings, inset browser windows, editorial type, ruled navigation, textured transitions and large footers. These ideas now share GMD paper/ink/Nile/pink tokens and square 5px hard depth. This is an evolving design preview, not a production deployment.

Arabic headings use Mada with a separate restrained scale: 44px maximum for section headings and 60px maximum for primary page titles on large desktops, 27–40px across mobile roles. Amiri remains paragraph text and Handjet selective labels. Latin display text uses the existing Perfectly Nineties font, alongside the existing body roles.
