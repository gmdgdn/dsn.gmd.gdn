# GMD Design System v0.01

## Review scope

Create an editable visual system in Pen using the Tavus source imports, verified screenshots, recovered fonts, and Brand Lite reference assets. Show the foundations and reusable components before implementing the homepage. GMD / gmd.gdn is the user-confirmed umbrella brand.

No homepage or application implementation is authorized in this review stage. Imported Tavus frames stay available as reference. Tavus logos belong to the reference brand and are not GMD identity assets.

## Product purpose

GMD collects and organizes Egyptian content and data, preserves context, and makes collections useful for distribution, research, products, and AI datasets. The system should support cultural archives alongside practical data portals and business tools.

Existing project context: Film (`film.gmd.gdn`) has an active frontend in `E:/Eslam Builds/elfilm/web`. Kayffa is a cultural archive and graph project currently represented by a scaffold, public shell, and admin APIs. The separate `E:/Eslam Builds/gmdgdn` repository is for `hire.gmd.gdn`; it is not proof that the umbrella homepage already exists.

User-planned directions include games, data portals, tools for different business types, and an Egyptian encyclopedia. Newly suggested projects must be labelled as proposals.

## Design requirements

- Warm paper, dark ink, editorial display type, precise utility labels, square geometry, and restrained offset shadows informed by the Tavus references.
- GMD identity and Egypt-focused content; no unsupported collection counts, customers, or launch claims.
- English and Arabic typography examples, mirrored RTL layouts, mixed-script identifiers, readable data and archive metadata.
- Semantic color roles for text, surfaces, actions, focus, success, warning, and error; legible contrast for normal text.
- Defined spacing, type scale, borders, radii, elevation, grid, and motion intent.
- Reusable navigation, buttons and states, search/filter controls, project/archive/dataset cards, provenance metadata, table rows, and empty states.
- Source attribution, rights, collection status, and dataset suitability as separate concepts. An archived work is not automatically available for redistribution or AI training.
- Small readable review boards and exported previews, with editable component IDs and token documentation.
