  - heading "Got questions?" [level=2]
  - generic: How do conversation minutes work?
  - paragraph: Conversation minutes measure live CVI usage — the time an AI human is actively in a session with a user, from the API call connect to disconnect. Each conversation is rounded to the nearest 6-second increment, and incurs a 30-second minimum charge regardless of duration.
  - paragraph: ‍
  - generic: What's included in CVI? Are there additional services needed?
  - text: A conversation through CVI includes everything you need, from LLM to Audio to WebRTC. There are no additional services or charges required to run an end to end conversation.
  - text: "It also includes all Tavus models: perception (Raven-1), conversation flow (Sparrow-2), and rendering (Phoenix-4.5)."
  - generic: How to minimize CVI usage while testing?
  - paragraph: When a conversation creation request is sent, a conversation is initiated and billed, regardless of if a participant joins. As a safeguard in case a conversation isn’t properly closed, a conversation automatically closes after 5 minutes if a participant isn’t present, however these limits can be modified by setting the properties when creating a conversation.
  - paragraph: You can also enable test_mode = ‘TRUE’ to test the conversation creation process without incurring any costs.
  - generic: What happens if I go over my plan minutes?
  - paragraph: Most paid plans include the ability to have pay-as-you-go usage with no overage cap so you can use extra minutes. You’re billed only for what you use beyond your monthly allowance — never paused, never throttled. Additional usage is paid at the stated rate.
  - generic: What are concurrent sessions / streams?
  - paragraph: Concurrent sessions are the number of live CVI conversations that can run at the same time across your account. If you’re on a 3-session plan and a 4th user tries to start a conversation, they’ll need to wait for an active one to end. These limits are to ensure GPU availability for all users.
  - paragraph: There are many ways to gracefully handle concurrency limits such as waiting states or audio only modes.
  - paragraph: We often refer to this interchangeably between concurrency, streams, and sessions.
  - paragraph: Enterprise plans have custom limits — reach out if you need more capacity.
  - generic: What is async/video generation, and how is it different from CVI?
  - paragraph: CVI is Tavus’s primary product, and is a realtime conversational AI interface.
  - paragraph: "Tavus also has video generation models available, which some customers use to additionally render MP4 videos as static assets (for ex: avatar video generation)."
  - paragraph: ‍
  - generic: What's the difference between audio-only and audio+video pipeline modes?
  - paragraph: Tavus CVI can be deployed with the same pipeline to either audio only use cases or audio + video use cases. Customers often use both pipelines. Pricing is the same, although discounts for audio only will be introduced shortly.
  - generic: What's a custom PAL face?
  - text: Custom faces are built from a single image or two minutes of training video. You can use a personal likeness, a character, or a brand-built persona. Faces live in your library and can be deployed across any number of conversations.
  - text: You have a certain number of custom faces available depending on your plan.
